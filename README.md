# quiz-satisfacao

 Quiz de Satisfação

1. Sobre o projeto

O Quiz de Satisfação é um projeto desenvolvido na disciplina de Design de Experiência e Prototipação.

A proposta é criar uma experiência digital simples, rápida e intuitiva para que clientes de um restaurante possam avaliar sua experiência no estabelecimento.

A solução foi projetada para ser utilizada em um tablet, permitindo que o cliente responda a um pequeno questionário de satisfação após o atendimento.

---

2. Problema

Muitos estabelecimentos possuem dificuldade para coletar opiniões dos clientes de maneira rápida e organizada.

Métodos tradicionais de avaliação podem ser pouco atrativos ou demorados, fazendo com que muitos clientes não deixem seu feedback.

O desafio do projeto é facilitar esse processo, criando uma experiência digital simples que permita ao cliente registrar sua opinião em poucos passos.

---

3. Solução proposta

A solução proposta é um quiz digital de satisfação no qual o cliente responde a perguntas rápidas sobre sua experiência no restaurante.

As avaliações são realizadas por meio de uma escala de satisfação, tornando o processo simples e fácil de entender.

O principal usuário da solução é o cliente do restaurante.

A experiência foi pensada para possuir uma navegação direta, com poucas etapas e informações apresentadas de maneira clara.
